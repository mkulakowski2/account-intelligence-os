# Skill: html_report_assembly

## Purpose

Assemble the final self-contained HTML account package.

## Required Sections

- Cover
- Executive Summary
- Company
- Hiring
- Strategic Initiatives
- Use Cases
- Contacts
- Active Implementers
- Tech Stack and Competitors
- community and package telemetry tools
- Outreach
- Account Plan
- Sources

## Rule

Do not invent missing sections. If required content is missing, return a quality gate failure.
