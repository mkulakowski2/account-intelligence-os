# Skill: outreach_generation

## Purpose

Generate exactly 10 outreach packages for the top 10 validated contacts.

## Components

- Subject A
- Subject B
- Email body under 200 words
- LinkedIn DM
- warm intro request if path exists
- 3 follow-ups

## Rules

- No templated language
- Each opening must be unique
- Each claim must reference contact or account evidence
- Active implementers can receive technical enablement notes
