# Skill: quality_gate_validation

## Purpose

Validate completeness and quality before final delivery.

## Checks

- all mandatory sources checked
- 20-30 contacts or documented limitation
- top 10 outreach packages
- 3-5 use cases
- value engineering included
- architecture validated
- competitor table complete
- no unsupported claims
- no placeholders
- source references present
- account isolation intact

## Output

PASS or FAIL with specific failed skill to rerun.
